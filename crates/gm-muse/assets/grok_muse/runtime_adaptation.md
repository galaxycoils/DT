### Path Mapping (Upstream → Grok-Muse)
All user and workspace paths resolve within Grok-Muse's isolated storage root and per-bot root via `SecurityGateway` (`RULE-PATH-002`):
- `/opt/muse/skills/` → `~/skills/` (read-only bundled skills; refreshed at startup)
- `/opt/hatch/` and `/opt/hatch/connectors/` → `~/connectors/`, `~/custom-connectors/`, and `~/spaces/`
- `~/workspace/custom-skills/` and `~/custom-skills/` → `~/custom-skills/` (user-created custom skills)
- `~/workspace/custom-connectors/` and `~/custom-connectors/` → `~/custom-connectors/` (user-created custom connectors)
- `~/USER.md`, `~/MEMORY.md`, `~/PROACTIVE_PREFERENCES.md`, `~/FEEDBACK.md`, `~/memory/`, `~/dreams/`, `~/goals/`, `~/side-chats/`, `~/spaces/` → shared user-level runtime storage (visible to authorized bots under untrusted `<*_data>` fences)
- `SOUL.md`, `IDENTITY.md`, `AGENTS.md`, `TOOLS.md`, `HEARTBEAT.md` → active bot's private directory under `bots/<bot_id>/` (writes require explicit `Irreversible` confirmation)
- `~/workspace/...` (general notes/work) and `sandbox://outbox/...` → active bot's `workspace/` and `outbox/` directories
- `/opt/hatch/bin/remote-storage` → **not available locally**. Write deliverables directly to `~/outbox/<filename>` or `~/workspace/goals/<goal-slug>/files/<filename>` and reference them with `sandbox://outbox/<filename>` or `![alt](sandbox://outbox/<filename>)`.
- `JARVIS_SANDBOX_API_SOCK` → **not available**; use the Grok-Muse step actions listed below instead of local Unix control sockets.

### Tool Mapping (Upstream Tool Calls → Grok-Muse Step Actions)
- `muse.read`, `muse.edit` → `WorkspaceReadFile`, `WorkspaceWriteFile`
- `muse.write` → `WorkspaceWriteFile`
- `muse.exec` → `WorkspaceShell` (confined by `SecurityGateway`)
- `muse.memory_search`, `muse.memory_get` → `MemorySearch`
- `muse.memory_explain` → `MemoryExplain`
- Forgetting (`skills/forget/SKILL.md`) → two-phase `ForgetPlan` (generates redacted plan ID) followed by `ForgetConfirm` (requires `Irreversible` user approval)
- `tool_search.load_tool_namespace` / skill discovery → `SkillSearch`, `LoadSkill`, `ConnectorSearch`, `LoadConnector`, and `CreateCustomSkill`
- External service APIs → `McpTool` (via `McpToolBridge`) or opaque vault credential leases `FillSecret` using `secret://keychain/<provider>` or `secret://1password/<vault>/<item>/<field>` (never embed plaintext secrets)
- `muse.create_options`, `muse.react_to_user_message` → `EmitDirective` (`options` or `reaction`)
- Goals (`~/workspace/goals/<slug>/`) → `GoalOp` (`create`, `update`, `complete`, `abandon`, `delete`, `create_subgoal` — max 1 subgoal level)
- Spaces (`~/spaces/<slug>/`) → `SpaceOp` (`create`, `edit`, `publish`, `unpublish`, `delete` — publish/delete require `Irreversible` confirmation)
- Bridge discretion (`~/side-chats/<chat-id>/DISCRETION.md`) → `UpdateDiscretion`
- Subagent delegation → `DelegateToBot` (fan-out depth is bounded by `muse.subagent_fanout_depth`)
- Computer use (host GUI when `allow_host_desktop` is enabled) → Set-of-Marks GUI actions (`Click`, `Type`, `Hotkey`, etc.) or `TakeTheWheel` for CAPTCHA/MFA walls.
