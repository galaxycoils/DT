# v0.6.1 Apple Silicon preview

This prerelease fixes headless OAuth fixture storage, Windows CI test selection, and DMG build-profile selection.

The downloadable installer is Apple Silicon only, built with the release profile and ad-hoc signing. Installation is manual. Developer ID signing and notarization remain outstanding. The package is ineligible for the signed updater. Intel Mac, Linux and Windows installers are outside this preview.

Download both files into the same directory and verify before opening the image:

```sh
shasum -a 256 -c GrokMuse-0.6.1-macos-aarch64-adhoc.dmg.sha256
```

The image contains GrokMuse.app and GrokMuseCUHelper.app. Follow the README installation and macOS permission instructions. Close running UI and services and retain a closed-app data backup before upgrading. Data recovery must use the compatible application and backup together.

CI checks macOS, Ubuntu and Windows. Local smoke testing uses isolated storage and mock inference to verify application launch, daemon connection and conversation persistence. Paid-provider behavior, clean-machine installation, native platform certification and hosted/mobile deployment require separate evidence. See [release readiness](../release-readiness.md).

The earlier v0.6.0 installer is a debug-profile, ad-hoc Apple Silicon preview. Its DMG bytes are retained. Its corrected checksum sidecar names the downloadable asset.
