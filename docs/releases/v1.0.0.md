# DT v1.0.0 Release Notes (Candidate Preparation)

`v1.0.0` prepares the DT branding, CLI (`dt` + `gm` compatibility alias), unified `dt doctor` recovery engine, cross-platform installer pipelines (`Install DT.pkg` inside ARM64/Intel DMGs, Windows NSIS 3.13 `.exe`, Ubuntu 24.04 `.deb`), Windows per-user SID-restricted named pipes, SQLx PostgreSQL + AES-256-GCM/HKDF hosted security, `HttpOnly; Secure` cookie sessions with CSRF, single-source UI tokens across all 4 clients, and renewable signed update metadata.

See [coverage inventory](../release/coverage-inventory.md) and [release readiness](../release-readiness.md) for the exact gates required before tagging and publishing public `v1.0.0` assets.
