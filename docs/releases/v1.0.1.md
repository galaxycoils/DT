# DT v1.0.1 Release Notes

Release branch: `codex/dt-stable-release` (`galaxycoils/DT`).

## Targets Included
- macOS Apple Silicon: `DT-1.0.1-macos-aarch64.dmg` (contains `Install DT.pkg`)
- macOS Intel: `DT-1.0.1-macos-x86_64.dmg` (contains `Install DT.pkg`)
- Windows x64: `DT-1.0.1-windows-x86_64-setup.exe`
- Windows ARM64: `DT-1.0.1-windows-aarch64-setup.exe`
- Ubuntu 24.04 x64: `dt_1.0.1_amd64.deb`
- Ubuntu 24.04 ARM64: `dt_1.0.1_arm64.deb`

## Key Fixes in v1.0.1
1. **Updater Backward Compatibility**: Preserves v1-compatible `dt-release.json` / `dt-release.sig` and `dt-update-metadata.json` / `.sig` for the four historical v1.0.0 targets while adding `dt-release-v2.json` / `.sig` and `dt-update-metadata-v2.json` / `.sig` for the full 6-asset v1.0.1 inventory (`windows-aarch64` and `linux-aarch64`).
2. **Release Signing & Packaging Safety**: Stages downloaded CI artifacts in `${{ runner.temp }}` outside the git checkout, verifies PE/ELF/Mach-O executable architectures before packaging, adds `NSMicrophoneUsageDescription` + `com.apple.security.device.audio-input` entitlements for macOS voice capture, and signs the Windows NSIS uninstaller via `!uninstfinalize`.
3. **Real Benchmarks & Per-Metric Evidence**: `xtask bench-hotpath` verifies decoded JPEG dimensions on all OSes, `xtask bench-rss` supports installed hash-verified binaries without rebuilding, and `verify-release-evidence.py` enforces >=30 raw samples per metric across all 8 certification targets.
4. **Full Doctor Recovery (`REC-01`)**: Captures nested directories/attachments in verified SQLite-consistent snapshots, journals rollback phases for resume via `dt-doctor resume`, preserves newer copies under unique recovery IDs, and preserves monotonic safety records (`monotonic-safety.json`) while invalidating restored sessions/approvals and pausing external jobs.
5. **Integer Microdollar Budget Admission (`BUD-01`) & Exact Approval Binding**: Uses `amount_micros` with `BEGIN IMMEDIATE` atomic reservation across independent connections and binds `ActionApprovalGrant` to exact action digest, workspace, destination, principal, job, and expiry.
6. **Hosted Server Replay & Readiness (`HOST-01`)**: Subscribes to live broadcasts before reading persisted event cursors to eliminate SSE reconnect gaps, immediately terminates streams upon membership revocation without disrupting other workspaces, adds PostgreSQL advisory migration locking and row-level security policies, and replaces the 401 health probe with `/api/v1/health/live` and `/api/v1/health/ready`.
7. **Support Bundle Allowlist & Byte Verification**: Builds diagnostic support bundles strictly from a non-secret allowlist and scans serialized bytes for secrets and identifying paths before setting `redaction_verified = true`.
8. **Desktop Launch, Direct Chat Reconciliation & Clean UI Redesign**:
   - Moves daemon launch and subscription off the UI startup thread into async `background()` with a 2-second subscription deadline, 2-second retry cadence, visible `Starting` / `Ready` / `Disconnected` connection banner + `Retry`, and per-conversation readiness tracking.
   - Adds optional `client_msg_id` (UUID) across `DaemonRequest::PostDirectChat`, `DirectChatStore::append_message_with_id` / `find_turn_by_client_id`, and `OpenBotSupervisor::dispatch_direct_chat` for idempotent persistence, matching `ChatTokenV1.message_id` streaming, UUID reconciliation, post-persistence inference error banners (`Message saved, reply failed` + `Retry reply` + `Open Provider Setup`), persistence-confirmed draft/attachment clearing, and immediate group `ChannelPost` receipt merging.
   - Refreshes desktop typography & palette with bundled Adobe Source Sans 3 `3.052R` (`Regular`, `Semibold`, and `SourceSans3-LICENSE.md` in `DT.app/Contents/Resources/`), quiet slate surfaces + blue accent, `780 pt` shared transcript/composer width, always-visible `Send`, scrollable overlay drawers below the `320 pt` chat floor, and clean vector icons/labeled controls.
9. **Fresh macOS Packaging & Linux CI OpenSSL Fix**: Uses freshly wiped per-architecture staging in `xtask`, verifies binary Mach-O architectures via `lipo -archs`, runs `strip -S` prior to signing, signs/verifies `xtask bundle` outputs, signs `Install DT.pkg` when a `Developer ID Installer` identity is present (reporting unsigned preview otherwise), and fixes Linux CI `find_openssl()` probing in `tools/make-release-manifest.py`.

## Known Preview & Certification Boundaries
- **Code Signing & Notarization**: Preview installers (`v1.0.1`) are distributed without Apple `Developer ID Application` / `Developer ID Installer` signing, Apple notarization, or Windows EV Authenticode signing (`--prerelease`).
- **Remaining Unverified Gates**: Physical non-macOS hardware validation, live paid provider accounts, 7-day stability soak, and whole-tree UI-open footprint optimization (`xtask bench-rss` reported `12.09 MiB` core idle < `50 MiB`, vs `212.64 MiB` UI open > `120 MiB` due to Metal/GPU swapchain and glyph atlas) remain open for full production certification.
