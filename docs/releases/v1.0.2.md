# DT v1.0.2 Release Notes

Release branch: `codex/dt-stable-release` (`galaxycoils/DT`).

## Targets Included
- macOS Apple Silicon: `DT-1.0.2-macos-aarch64.dmg` (contains `Install DT.pkg`)
- macOS Intel: `DT-1.0.2-macos-x86_64.dmg` (contains `Install DT.pkg`)
- Windows x64: `DT-1.0.2-windows-x86_64-setup.exe`
- Windows ARM64: `DT-1.0.2-windows-aarch64-setup.exe`
- Ubuntu 24.04 x64: `dt_1.0.2_amd64.deb`
- Ubuntu 24.04 ARM64: `dt_1.0.2_arm64.deb`

## Key Fixes in v1.0.2
1. **Expo Mobile Client Startup & Parity (`clients/mobile/`)**:
   - Restored Expo Router entrypoint (`"main": "expo-router/entry"`) and added CI iOS/Android bundle export verification (`npm run export:ios`, `npm run export:android`).
   - Fixed nested routine `{ routine, next_run_utc }` display and run history, Activity `body` rendering, Channels on Inbox, persisted inline approval cards with Approve/Deny/Expired updates, `client_msg_id` idempotent reply-failure retry + Provider Setup recovery, dynamic dark/light theme tokens, and full disconnect state wipe + request abort.
2. **Hosted Control Plane, Active PostgreSQL & Per-Workspace Isolation (`hosted.rs`, `web.rs`, `gm-daemon`)**:
   - Wired `PostgresHostedStore` as an active hosted backend via `HostedPlaneBackend` when `DT_DATABASE_URL` or `DATABASE_URL` is configured, including `POSTGRES_MIGRATION_V4` and verified `VACUUM INTO` + SHA-256 backed-up SQLite-to-PostgreSQL migration.
   - Added operator-only `POST /api/v1/workspaces`, isolated `/api/v1/*` handlers and SSE streams per authenticated workspace `worker_dir`, and enforced honest `"expired"` updates on stale approvals.
3. **Hosted React Web & Companion Web UI (`clients/web/`, `companion_ui.source.js`)**:
   - Rebuilt `clients/web` with zero horizontal overflow at 390px mobile viewports (Dark and Light themes), clean signed-out connection screen, complete state clearing + request cancellation on sign-out, persisted approval cards, `"Message saved, reply failed"` + idempotent `Retry reply` + `Open Provider Setup`, nested routine/run history, Activity `body`, and Channels/Goals/Pages/Providers/Connectors/Marketplace/Billing/Doctor tabs.
   - Updated the embedded Companion Web UI (`63,788` bytes, strictly under the `64 KiB` budget) with `client_msg_id` reply-failure recovery, `Cmd/Ctrl+Shift+M` -> Studio/Templates, working Dictation toggle, and Local Components installer UI.
4. **Desktop Controls, Real Voice/Dictation & Compact Sidebar (`gm-ui`, `voice.rs`, `control_server.rs`)**:
   - Fixed `Cmd/Ctrl+Shift+M` -> Studio, `Cmd/Ctrl+B` sidebar toggle + persistence, `Cmd/Ctrl+Shift+F` expand + search, `Cmd/Ctrl+D` dictation, and Shortcuts cheat-sheet parity.
   - Replaced placeholder Voice/Dictation controls with a real consent-gated `VoiceSessionManager` (with immediate playback teardown on stop/barge-in/consent revocation and direct Local Components recovery).
   - Brought the compact desktop sidebar to parity with expanded mode (Create, Search, Activity, Pages, Bots + Channels, Connect apps, Settings, Workspace), cleared stale pending approval cards on expiry/resolution, and exposed Connector probing, scope-confirmed Marketplace installs, Billing status, and Local Components management.
5. **Pinned Local Components Catalog & Resumable Installer (`docs/release/component-catalog.json`, `components.rs`, `doctor.rs`)**:
   - Populated all 8 optional components (`qwen2-vl-2b`, `smolvlm`, `smolvlm2`, `vlm_worker`, `whisper-stt-base-en`, `speech_tts`, `vm_image`, `vm_firmware`) across all 6 OS/arch targets with verified upstream URLs, exact byte sizes, and SHA-256 digests.
   - Added streaming resumable `ComponentManager` with post-install header + SHA-256 verification and live Doctor capability readiness reporting.
