# DT v1.0.7

This prerelease addresses storage recovery, hosted workspace isolation, mobile enrollment, local models, and voice. Doctor now snapshots the nested memory database through SQLite and checks it for corruption. Ordinary database opens preserve the active file on failure. Run `dt doctor check` after a manual upgrade.

Mobile connects to a hosted workspace with a one-time enrollment token and stores the resulting revocable session. Use `dt models install smolvlm` followed by `dt models probe smolvlm image.jpg` to check offline image inference.

Download a package and its matching SHA-256 file. Back up your profile with DT stopped before upgrading. This CI-built prerelease uses ad hoc macOS signatures and unsigned Windows installers. Publisher-signed updates and full native, live-account, and soak certification are pending. [Installation and checksums](https://github.com/galaxycoils/DT/blob/v1.0.7/README.md#downloads)
