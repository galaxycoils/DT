# v0.5.0 — GrokBot workspace and lightweight companion

- Shared dark/light workspace chrome, adaptive Bots/Groups sidebar, Feed, Goals,
  Spaces, Audit, Bot Details, keyboard palette, and responsive mobile navigation.
- Native profile/routine editing, webhook keys and recent runs, library filters,
  memory provenance/discretion/verified forgetting, channel metadata, avatar/media
  previews, attachments and code-aware composer behavior.
- Authenticated fetch SSE with incremental frame parsing, reconnect cancellation,
  bounded transcript rendering, and keyed message DOM updates. No timer polling.
- Scripts-only Space iframe on its dedicated loopback port; canonical capability
  entry URLs preserve authorization for relative assets through a redirect.
- Secure forms and Vault stay outside model messages. Custom rules, CSV imports,
  usage attribution, connector metadata, teach-a-task and bridge setup states are
  backed by the local stores and authenticated APIs.
- Real update checking/downloads share the daemon updater. Downloads require the
  configured trusted publisher key and authenticated release manifest; installing
  an unverified asset is not offered as a fallback.
- Default native Glow renderer with optional WGPU, bounded texture/decode limits,
  event-driven repaint, and capture only while the viewer is open.
- Reproducible companion build and DOM/browser checks in CI; updated PipeWire
  ownership APIs and smaller macOS packaging staging.

Cloud services (mail, voice/meetings, payment checkout, OAuth bridges) require
configured adapters. Their setup states do not simulate a connected service.
Hardware permissions and native process RSS/CPU targets require certification on
an unlocked desktop; passing headless tests does not certify those measurements.
