# DT `v1.0.3` Release Notes — Pre-Shipping Hardening, Interactive Cross-Device UX & 100% Coverage Inventory

## Highlights

1. **Interactive Cross-Device React Web & Expo Mobile Experience (`clients/web/`, `clients/mobile/`, `tools/generate-ui-tokens.py`)**:
   - **Responsive 3-Tier Workspace Hierarchy**: Drag-resizable desktop sidebar (`240px–480px`), 1-click collapse into a `72px` icon rail, and a mobile slide-over drawer (`<= 768px`) with backdrop blur.
   - **Geometric Coworker Avatars & Live Presence**: Unique geometric shapes (`circle`, `squircle`, `hexagon`, `diamond`) for `@muse`, `@researcher`, `@coder`, and `@guardian` with animated eye-blink keyframes, live status dots, and active status phrases.
   - **Command Palette (`⌘K` / `Ctrl+K`)**: Instant modal fuzzy switcher across coworkers, `#channels`, views, routines, spaces, DT Doctor diagnostics, and theme toggles.
   - **Per-Target Draft Isolation & Live Transcripts**: Fixed conversation switching so drafts remain isolated per `dm:<bot_id>` / `channel:<id>` in `sessionStorage` while loading historical transcripts from `/api/v1/direct/:bot_id/messages` and `/api/v1/channels/:id/messages`.
   - **Smart Typography Composer & Inline Approval Cards**: Automatic `->` to `→` smart arrow replacement outside inline/fenced code blocks with single-Backspace undo, contextual empty-state starter prompt chips, and non-blocking inline Tier-3 **Approval Cards** (`Approve` / `Deny`).
   - **Interactive Routines, Split-View Space Sandbox, Provider Pipeline & DT Doctor**:
     - 1-click **`Trigger Now`** execution on routine cards.
     - Split-view static Space creator + live isolated iframe preview (`sandbox="allow-scripts"`).
     - Visual 4-stage Provider Connection pipeline (`Unconfigured → Saved → Discovered → Verified`) and live Connector capability prober.
     - Structured DT Doctor installation readiness scorecard with 1-click JSON export.
2. **Full CLI & `/api/v1` Parity (`crates/gm-daemon`, `crates/gm-openbot`)**:
   - Wired `dt patch`, `dt routines trigger`, `dt diagnostics prune-backups`, and `dt diagnostics recover-database` in the top-level CLI (`dt` and `gm`).
   - Added `POST /api/v1/routines/:id/trigger`, returned user workspace memberships in `GET /api/v1/workspaces`, and updated `POST /api/v1/marketplace/:id/update` to resolve built-in catalog items by ID.
3. **100% Release Coverage Inventory Verification (`docs/release/coverage-inventory.json`, `tools/test_release_tools.py`)**:
   - Implemented and verified all **30/30 required `test_ids`** across all **26 required capability rows** in `docs/release/coverage-inventory.json`, enforced automatically by `test_coverage_inventory_test_ids_exist_in_codebase`, with **384/384 workspace tests** passing under `cargo nextest`.
4. **Cross-Platform Packaging & Docker Hardening (`xtask`, `tools/installers/linux/build-deb.sh`, `deploy/docker/Dockerfile`)**:
   - Enforced `umask 022` and `0755` directory modes in `build-deb.sh`, added `dt` and `dt-doctor` symlinks to `xtask install`, added cross-platform JPEG encoding benchmarks in `xtask bench-hotpath`, and updated `deploy/docker/Dockerfile` with PipeWire/XCB build packages and the `gm` CLI binary.
