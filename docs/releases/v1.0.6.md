# DT v1.0.6

DT Doctor now checks `memory.sqlite/memory.db` on profiles where `memory.sqlite` is a directory. This fixes a false `migration_state` failure in v1.0.4 and v1.0.5. When SQLite requires a writable connection to validate the full-text index, Doctor checks a temporary copy and leaves the original database untouched.

Install the package for your platform and rerun `dt doctor check`. The fix uses your existing storage layout and requires no data migration.

## Downloads

Choose the CI-built installer for Ubuntu 24.04, macOS, or Windows, or the standalone Linux x86-64 archive. The Ubuntu packages and Linux archive include the React client. On macOS and Windows, use the matching web client bundle. Verify each download with its SHA-256 sidecar. [Installation and checksum instructions](https://github.com/galaxycoils/DT/blob/v1.0.6/README.md#downloads)

The macOS apps use ad hoc signatures and the Windows installers ship without Authenticode. [Release readiness](https://github.com/galaxycoils/DT/blob/v1.0.6/docs/release-readiness.md)
