# DT v1.0.5

This patch release makes the React client usable with a local DT daemon and fixes Page previews and live reconnect.

- Connect at `http://127.0.0.1:7433/app/` with the Companion token. Local sign-out clears the token and cancels the event stream.
- Reconnect uses the last durable event ID, including when the connection drops during a streamed reply.
- Page previews retain a separate loopback origin and scripts-only sandbox. The app shows the required daemon URL or upgrade when an inline preview is unavailable.
- Caddy redirects the HTTPS root to `/app/`. Hosted enrollment, secure cookies, CSRF checks, and tenant isolation continue to apply.
- The new README documents platform downloads, checksums, web bundle setup, and foreground and background startup.

## Upgrade

Install the package for your platform. The Debian packages, Linux binary archive, and Docker image include the web client. On macOS and Windows, use the matching web bundle from this release. For split-view Pages, run the v1.0.5 daemon and open the canonical loopback app URL.

## Release assets

The release includes six CI-built installers for macOS, Ubuntu 24.04, and Windows across x86-64 and ARM64, plus a standalone Linux x86-64 archive and the React web bundle. Verify each download against its SHA-256 sidecar. Installer assets include build metadata and an SBOM.

These packages use the public CI build. The macOS apps use ad hoc signatures, and Windows Authenticode and signed update certification use the separate release-evidence workflow.
