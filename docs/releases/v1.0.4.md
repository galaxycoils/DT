# DT `v1.0.4` Release Notes — Full Unification, Same-Origin `/app` Web Hosting, PostgreSQL CI Verification & Security Hardening

## Highlights

1. **Unified `master` (`v1.0.2` Backend + `v1.0.3` Interactive UX)**:
   - Merged the previously unmerged `codex/dt-stable-release` (`v1.0.2`) work into `master` via a true 2-parent merge commit with zero backend regressions verified line-by-line:
     - **Pinned Local Component Catalog (`docs/release/component-catalog.json`, `crates/gm-daemon/src/components.rs`)**: All 8 optional local runtimes and models (`qwen2-vl-2b`, `smolvlm`, `smolvlm2`, `vlm_worker`, `whisper-stt-base-en`, `speech_tts`, `vm_image`, `vm_firmware` — 15 OS/arch targets, `sequence: 3`, valid through `2027-11-19T00:00:00Z`) with resumable chunked download and SHA-256 verification.
     - **Active PostgreSQL Hosted Control Plane (`crates/gm-openbot/src/hosted.rs`, `crates/gm-openbot/tests/postgres_hosted.rs`)**: `PostgresHostedStore` + `HostedPlaneBackend` (migrations V1–V4, row-level tenant isolation, AES-256-GCM + HKDF secret vault, and SHA-256-verified SQLite-to-PostgreSQL migration), backed by **7 real PostgreSQL 16 integration tests** proven in CI (`postgres-integration`).
     - **Consent-Gated Voice & Desktop Redesign (`crates/gm-openbot/src/voice.rs`, `crates/gm-ui/`)**: Managed local Whisper STT / TTS via `VoiceSessionManager`, embedded `SourceSans3` fonts, and full compact-sidebar & keyboard shortcut parity.
     - **Renewable Update Metadata & Operations Guide (`tools/renew-update-metadata.py`, `docs/OPERATIONS.md`)**: Documented renewal CLI flags, GitHub Actions workflow inputs, and monotonic `sequence` rules.
2. **One-Command React Web App Hosting at `/app` (`crates/gm-openbot/src/web.rs`, `crates/gm-daemon/src/lib.rs`, `clients/web/vite.config.ts`)**:
   - `dt serve` now hosts the built React web app directly at **`http://127.0.0.1:7433/app/`** on the same origin as `/api/v1/*` (with `308` redirect from `/app`, SPA fallback, immutable caching for `/app/assets/*`, strict CSP + `X-Frame-Options: DENY` + `X-Content-Type-Options: nosniff`, and canonical path-traversal blocking).
   - Bundled `clients/web/dist` automatically into the Ubuntu `.deb` package (`/usr/share/dt/web`) and `deploy/docker/Dockerfile` (`DT_WEB_DIST=/usr/share/dt/web`), plus `/app` reverse-proxy handling in `deploy/docker/Caddyfile`.
   - Added `clients/web/vite.config.ts` dev proxy (`localhost:5173` → `127.0.0.1:7433`) and `cargo run -p xtask -- dev` to launch `dt serve` and Vite together with Ctrl-C teardown.
3. **Actionable First-Run `dt doctor` Hints (`crates/gm-daemon/src/doctor.rs`)**:
   - Added non-failing `info`/`warn` checks for `web_app_present`, `optional_components`, `hosted_database`, and `metadata_expiry` without altering repair or readiness semantics.

## Fixes & Security Hardening

- **Workspace Version Synchronization & Drift Guard**: Synchronized `Cargo.toml`, `clients/web/package.json`, `clients/mobile/package.json`, `clients/mobile/app.json`, `docs/release/release-inventory.json`, and `docs/release/coverage-inventory.json` to `1.0.4`, enforced by `test_versions_are_in_sync` in `tools/test_release_tools.py`.
- **30-Day Signed Metadata Expiry Guard**: Added `test_signed_metadata_not_expiring_soon` to fail CI whenever signed metadata approaches expiration within 30 days.
- **Dependabot `minimatch` Advisory Fix**: Overrode `minimatch` to `^11.0.1` in `clients/mobile/package.json` (`npm audit --omit=dev`: **0 vulnerabilities** on both `clients/web` and `clients/mobile`).
- **Mobile Drawer `721px–768px` Fix**: Resolved CSS cascade conflict between `.dt-mobile-only` and `.dt-mobile-menu-btn` in `clients/web/src/App.tsx`.
- **Coverage Inventory & Verification**: **422/422** workspace tests passing (`cargo nextest`), X11 native test passing, **36/36 required `test_ids`** across **28 required rows** (including new `WEB-APP-01` and `HOST-PG-01`), and Companion Web UI bundle at `63,788` bytes (`< 64 KiB`).

## Upgrade Notes

- **Upgrading from `v1.0.3` or `v1.0.2`**: Install the `v1.0.4` package directly. Existing channels, messages, routines, and settings are preserved and verified via isolated `v1.0.3 → v1.0.4` and `v1.0.2 → v1.0.4` upgrade tests (`dt doctor check --json`: 0 failed checks).
- **Hosted Operators Switching to PostgreSQL**: Set `DT_DATABASE_URL=postgres://...` before starting `dt serve`. Existing `hosted-control.sqlite` stores migrate idempotently with a `VACUUM INTO` + SHA-256 verified backup; see `docs/OPERATIONS.md`.
