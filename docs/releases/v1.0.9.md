# DT v1.0.9

The Mac desktop now maps its system fallback font once, preserving the same glyph coverage while reducing memory use. Windows model worker installation uses the patched ZIP reader. Cargo fetches the pinned Darius revision automatically when building from source.

Download the installer for your platform and verify its SHA-256 before upgrading. This prerelease uses ad hoc macOS signatures and unsigned Windows installers. Updates are manual. Native device testing, live accounts and the seven-day soak are still pending. [Downloads and installation](https://github.com/galaxycoils/DT/blob/v1.0.9/README.md#downloads)
