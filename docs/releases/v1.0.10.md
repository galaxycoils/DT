# DT v1.0.10

All six desktop installers now include the React web app out of the box alongside the standalone Linux archive and Docker image, so `/app/` and `dt doctor check` work immediately after installation on macOS and Windows. DT Doctor checks desktop session readiness accurately on Linux and Windows, validates snapshot and rollback IDs, and keeps host CLI probes disabled until isolated VM execution is certified. On Apple Silicon, DT measures 13.6 MiB idle and 90.6 MiB with the native desktop UI open across 30 samples.

Download the installer for your platform and verify its SHA-256 before upgrading. This prerelease uses ad hoc macOS signatures and unsigned Windows installers. Updates are manual. Native mobile and non-Mac hardware testing, live accounts, and the seven-day soak are still pending. [Downloads and installation](https://github.com/galaxycoils/DT/blob/v1.0.10/README.md#downloads)
